# Black Bot для Black Squad

Бот Discord для клана Black Squad в ROB RUN. Требуется Python 3.11 или новее. Настройки каналов, заявки, XP, активность и временные голосовые комнаты хранятся в отдельной SQLite-базе.

## Подключение

1. Создай приложение **Black Bot** в Discord Developer Portal. На вкладке Bot включи **Server Members Intent** и **Message Content Intent**.
2. Пригласи бота со scopes `bot` и `applications.commands`. Ему нужны Manage Roles, Manage Channels, Manage Nicknames, Change Nickname, Kick Members, View Audit Log, Move Members, Connect, View Channel, Send Messages, Read Message History, Embed Links и Attach Files. Подними управляемую роль бота выше всех ролей, которые он должен выдавать, снимать или модерировать.
3. Скопируй `.env.example` в `.env`. Укажи токен Black Bot и ID сервера Black Squad. Для хостинга укажи постоянный путь `DATA_DIR`. Токен хранится локально. Запускай один экземпляр на сервер.
4. Установи зависимости командой `python -m pip install -r requirements.txt`. Точка входа на хостинге — `main.py`, команда запуска — `python main.py`.
5. Запусти `/setup` с правами администратора. Команда создаёт роли, категории, каналы и панели. `/admin` позволяет кнопками назначить существующие каналы. При назначении бот заменяет разрешения канала правилами выбранного раздела. `/server_audit` показывает недостающие права, роли, панели и каналы вне схемы. Старые неназначенные каналы сохраняются.
6. Назначь **Босс** главе сервера, **Зам** и одну должность каждому руководителю направления, **Рекрутёр** сотрудникам набора и **Свояк** действующим участникам. Проверь аудит и пройди верификацию с обычного аккаунта.

## Набор

- При входе новый участник получает **Не верифицирован**. Кнопка верификации открывает форму `Ник (Имя)`. После сохранения бот ставит этот серверный ник, выдаёт **Кто ты, воин?** и открывает правила, описание, форму заявки и голосовой канал собеседования.
- Заявка заполняется в два шага. В первом — имя и возраст, игровой ник, часы в ROB RUN, время игры и PvP/PvE. Можно выбрать обе специализации. Во втором — предыдущие кланы и ожидания.
- PNG-карточка уходит в закрытый канал заявок. Штаб или рекрутёр берёт её на себя. Решение и возврат в очередь доступны взявшему заявку.
- При одобрении бот ставит серверный ник `Игровой ник (Имя)` в пределах лимита Discord, выдаёт **Пробник** и выбранные специализации. `/promote member:` переводит в **Свояки**. При отказе бот исключает кандидата с сервера.

## Активность и логи

- У пробников и состава записываются сообщения, время в голосовых и дата последней активности. Голосовой AFK-канал сервера исключён из подсчёта. `/activity` показывает статистику, `/rank` показывает XP и звёзды, `/top` выводит десятку.
- За сообщение начисляется 10–25 XP с интервалом в 60 секунд, за каждые пять минут в голосовом — 10 XP. Пороги звёзд — 100, 400, 900, 1600 и 2500 XP. У участника одна звёздная роль текущего уровня.
- Black Bot проверяет неактив при запуске и каждый час. Через 30 дней без активности участник клана исключается. Владелец, Босс и администраторы освобождены от автокика. Для действующего состава без истории отсчёт начинается с постановки на учёт. `/inactive` показывает, кого бот считает неактивным.
- «Логи сервера» получают события участников, сообщений и голосовых. «Админ-логи» получают действия модерации из аудита Discord, решения по заявкам и автокики.
- Лобби «Создать комнату» создаёт временный войс, который удаляется после выхода всех участников. Владелец управляет названием, лимитом, входом, видимостью и передачей комнаты через PNG-панель. Название, лимит и параметры доступа сохраняются для следующей комнаты. Если владелец выходит, бот передаёт комнату оставшемуся участнику.
